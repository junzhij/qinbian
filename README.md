# 秦编

个人本地使用的校园图文编排书房。Nuxt 4 / Vue 3 前端，Fastify 5 后端，SQLite 数据库。

## 启动

本机依赖已安装。进入本目录后运行：

```sh
./run dev
```

打开 http://127.0.0.1:3030 。前端通过同源接口访问本机3031端口的后端。

生产版本：

```sh
./run build
./run start
```

运行器会选择 Node.js 24，不改变系统 Node。可用 `QINBIAN_NODE` 指定 Node 24 的绝对路径。新电脑首次运行需先使用 Node 24 执行 `pnpm install`。

### 局域网访问

```sh
./run start --lan
# 开发模式也支持：./run dev --lan
```

终端会显示本机的局域网地址。同一Wi-Fi或局域网中的设备使用该地址打开秦编，访问同一份文章和资源。局域网模式会记在本机，之后普通启动也会沿用；`./run start --local`可切回仅本机访问。内部API仍只监听本机，通过网页服务转发请求。

局域网HTTP下，浏览器可能使用手动复制正文窗口；组件插入和复制组件不依赖HTTPS专有的随机编号接口。

## 日常使用

- 资源库包含组件、编排模板和配色卡。“山海知行”是内置套组，修改原件时会另存副本。
- 图片素材库保留原图，包括GIF；多篇文章可以重复使用同一图片。
- 编排台支持组件拖动、富文本、图片与数据设置、自动保存和历史恢复。
- 配色卡包含3—6色，每色含主题、强调、减淡三档。颜色名称可自由更改，稳定代号不变。
- 右侧“配色与映射”修改整枚组件的颜色关系；选中文字后，上方颜色按钮可选择“主题色”或“自定义”。自定义只影响所选文字。
- 字段在右侧修改；普通文字、标题及div文本框也能在画布直接编辑。百分比字段会随数值同步变化。
- AI制作支持生成组件、修改组件、生成配色卡，默认DeepSeek V4 Pro，可切换Flash。明确写“三色设计”等要求时，需求中的色数优先于默认选择。
- 导出正文使用真实内联样式并嵌入图片，不包含编辑控件与绑定标记。公众号后台的粘贴、图片接收及手机效果仍需实际账号核对。

## 本地数据与备份

数据位于本目录的 `data/`：数据库 `qinbian.sqlite`，原图 `uploads/`，缩略图 `thumbs/`。

设置页可以下载完整ZIP备份，并恢复备份。恢复前自动留存当前数据。组件、模板和文章采用快照，调整套组配色或源组件不会改写已有稿件。删除的资源可以从回收站恢复；正在被引用的图片不能删除。

## DeepSeek配置

后端默认读取上一层记者团目录的 `env`，兼容已有的带说明前缀的单行密钥，也支持 `DEEPSEEK_API_KEY` 环境变量。密钥不进入前端、数据库、构建文件或备份。设置页只显示是否已配置，可单独检查连接。

## 制作规范与开发

项目内 `skills/component-design/SKILL.md` 定义字体、配色和占位符规范。完整绑定协议见 `docs/bindings.md`。核心解析器由前后端共用。

```sh
./run typecheck
./run test
./run build
```

`scripts/verify-deepseek.mjs` 和 `scripts/verify-bindings-ai.mjs` 是手动真实API验证，会消耗DeepSeek额度，不会随普通测试自动运行。

当前内置96个组件、8套模板及2张配色卡。旧版1、2草稿可在“我的文章”导入。旧静态组件库和交接材料保留在记者团原目录。
