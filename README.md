# 秦编

个人本地使用的校园图文编排书房。Nuxt 4 / Vue 3 前端，Fastify 5 后端，SQLite 数据库。

## 启动

本机依赖已安装。进入本目录后运行：

```sh
./run dev
```

本机工程目录为 `/Users/jjz/qinbian`。文章、资源、原图及 Git 记录随工程保留；密钥文件为工程根目录的 `env`。

打开 http://127.0.0.1:3030 。前端通过同源接口访问本机3031端口的后端。

生产版本：

```sh
./run build
./run start
```

运行器会选择 Node.js 24，不改变系统 Node。可用 `QINBIAN_NODE` 指定 Node 24 的绝对路径。新电脑首次运行需先使用 Node 24 执行 `pnpm install`。

### 局域网访问

```sh
./run start --lan
# 开发模式也支持：./run dev --lan
```

终端会显示本机的局域网地址。同一Wi-Fi或局域网中的设备使用该地址打开秦编，访问同一份文章和资源。局域网模式会记在本机，之后普通启动也会沿用；`./run start --local`可切回仅本机访问。内部API仍只监听本机，通过网页服务转发请求。

局域网HTTP下，浏览器可能使用手动复制正文窗口；组件插入和复制组件不依赖HTTPS专有的随机编号接口。

## 日常使用

- 默认首页为文章列表。左侧导航为文章、资源库、图片素材，下方为主题套组；在资源库中浏览、编辑、复制和管理组件、模板与配色卡。进入编排台或组件编辑时，左侧导航收为图标栏。“山海知行”是内置套组，修改原件时会另存副本。
- 图片素材库保留原图，包括GIF；多篇文章可以重复使用同一图片。
- 圆形或指定比例的图片位置会自动裁切，保留原图并生成副本；点击“调整裁切”可拖动、缩放，选择矩形、圆形、圆角及比例。素材库也可裁切后另存，GIF保留动画。
- 编排台支持组件拖动、富文本、图片与数据设置、自动保存和历史恢复。插入栏可按套组、分类、来源组合筛选，自建组件显示名称首字。
- 配色卡包含3—6色，每色含主题、强调、减淡三档。颜色名称可自由更改，稳定代号不变。
- 右侧“配色与映射”修改整枚组件的颜色关系；选中文字后，上方颜色按钮可选择“主题色”或“自定义”。自定义只影响所选文字。
- 字段在右侧修改；普通文字、标题及div文本框也能在画布直接编辑。百分比字段会随数值同步变化。
- AI制作支持生成组件、修改组件、生成配色卡，默认DeepSeek V4 Pro，可切换Flash。明确写“三色设计”等要求时，需求中的色数优先于默认选择。
- 导出正文使用真实内联样式并嵌入图片，不包含编辑控件与绑定标记。

- AI 制作可选择“自由创作／数据图表／分隔符”；所有下拉选项使用自绘选择器，支持键盘、Esc及窄屏定位。
- 数据图支持折线、面积、柱状、条形、饼图和环图；原始数据可修改，图形同步重绘，复制与导出内嵌PNG。
- 分隔符支持细线、双线、点状和章节题签，可调整配色、留白、宽度和文案。
- 右栏“整篇文章”可设文章背景，支持主题减淡色及自定义底色；自动保存、撤销重做、复制文章、另存模板和导出均保留。组件内部已有底色保留。
- 右栏“整篇文章 → 全文样式”按正文、大标题、小标题、图注与署名、引文统一设置字号、字体、行距、对齐、缩进及段落留白。先预览再应用，整次操作可撤销；默认保留单独修改的文字和独立区域。旧文章打开时不自动套用规则，停用可还原原有排版。
- 顶栏指针按钮进入“点选元素”：悬停显示边界，点击选择段落、图片或容器；右侧可沿层级深入或向外选，调整尺寸、颜色、边框与留白，标记文字角色，或返回文字编辑、图片裁切。
- “用 AI 修改此元素”只发送所选区域与相关字段。文字、图片、数值默认锁定，候选预览后才应用；文章继续修改后会核对版本。刷新后重新选中原目标，可继续审阅最近尚未应用的局部候选。

## 字体兼容状态

默认新正文不指定font-family，跟随公众号自身字体；本地预览使用平台公布的字体栈回退。秦编界面的思源宋体不进入导出正文。用户主动选择的设备宋体、黑体、楷体及旧组件原有字体会保留。依据：[微信公众平台前端团队字体规范](https://github.com/wechatjs/verify-article-structure-spec/blob/main/verify_article_structure.md#3字体使用规范)。

## 本地数据与备份

数据位于本目录的 `data/`：数据库 `qinbian.sqlite`，原图 `uploads/`，缩略图 `thumbs/`。

设置页可以下载完整ZIP备份，并恢复备份。恢复前自动留存当前数据。组件、模板和文章采用快照，调整套组配色或源组件不会改写已有稿件。删除的资源可以从回收站恢复；正在被引用的图片不能删除。

## DeepSeek配置

后端默认读取工程根目录的 `env`，兼容已有的带说明前缀的单行密钥，也支持标准 `DEEPSEEK_API_KEY=…` 格式及同名环境变量覆盖。`QINBIAN_ENV_FILE` 可指定其他文件。密钥不进入前端、数据库、构建文件、Git 或备份。设置页只显示是否已配置，可单独检查连接。

## 制作规范与开发

项目内 `skills/component-design/SKILL.md` 定义字体、配色和占位符规范。完整绑定协议见 `docs/bindings.md`。核心解析器由前后端共用。

```sh
./run typecheck
./run test
./run build
```

`scripts/verify-deepseek.mjs` 和 `scripts/verify-bindings-ai.mjs` 是手动真实API验证，会消耗DeepSeek额度，不会随普通测试自动运行。

当前内置96个组件、8套模板及2张配色卡。旧版1、2草稿可在“我的文章”导入。旧静态组件库和交接材料保留在记者团原目录。
