# 数据图规范与输出协议

支持 line 折线、area 面积、bar 柱状、horizontalBar 条形、pie 饼图、donut 环图。趋势用折线，比较用柱状/条形，连续规模用面积；互斥分类占同一整体才用饼/环，2—6类且只用一组数据。多系列最多3组、每组最多12点，长度必须与分类一致。

不得用CSS渐变、旋转边框、空圆、SVG或Canvas伪造图表。图形交给受控渲染器，预览与导出均为PNG；图表描述及字段仍留在组件中供修改，导出只保留实际图片和文字。标题、图注、来源用普通可编辑HTML，不把整个组件画成图片。

## HTML节点

在section上声明data-qb-chart，属性值是JSON。不要自己填img或绘图代码：

```html
<section data-qb-chart='{"type":"line","labels":["{{label1}}","{{label2}}","{{label3}}"],"series":[{"name":"{{seriesName}}","values":["{{value1}}","{{value2}}","{{value3}}"]}],"colors":["color1-regular","color2-regular","color3-regular"],"unit":"{{unit}}"}'></section>
```

fields为label1—3、seriesName、unit声明text字段，为value1—3声明number字段；values给初值。数值引用只能是单个字段{{value1}}，不写value1+value2等表达式。未提供的数据默认留空字符串，渲染为缺失值；若用户明确要求演示，可给示例数值，但标题或图注必须写“示例数据，使用前请替换”。不能编造官方统计、数据来源或结论。

## 数据与视觉

- 分类、系列、单位、来源和统计时段写清楚；时间序列按真实时间排序，并同步排列数值，不把分类当连续时间。
- 柱状/条形从零起算，负数放在零线另一侧。面积图从零起算。折线不做夸张截轴或虚构平滑，缺失点留断口，不当作0，也不跨空连接。
- 饼/环用非负原始值按总和计算角度。若输入是百分比，先核对总和；不靠手写累计百分比、无效公式凑圆。总和为0或有缺失项时显示待补数据，不伪造分布。百分比由渲染器处理舍入，不加3D透视。
- 按主题槽位选颜色，深色作主要数据、减淡色作辅线。多系列使用可分辨颜色与线型；图例和数值必须能独立理解，不只靠颜色。避免双Y轴。
- 图表保持移动端易读，320px不溢出。标签短而清晰，完整分类和原始数值由渲染器同时输出成文字；单位不得藏在工具提示里。长数据集应拆分或请用户选择范围，不静默删点。
- 仅修改标题或配色时保留所有真实数值、分类顺序、单位与来源；修改数值后图形必须同步重绘。返回完整组件JSON，保留data-qb-chart和字段id。
