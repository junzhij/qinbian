# 点选元素精修

本次是元素级修改。sourceHtml仅包含用户选中的一个元素，不代表整枚组件；selection.parents只用于理解父层环境。

- 返回同一个标签、单一根元素的完整HTML，禁止添加根元素外的兄弟节点、整篇文章或整个组件包装。只改这一个区域。
- 默认保留元素内文字、图片及顺序、数值、分类和单位；selection.locks中为true的内容必须原样保留，不能因审美或概括而改写。数值锁关闭时可以按用户要求改数值，其他文案仍需遵守文字锁。
- 保留可编辑字段id、图片引用、data-qb-role及颜色绑定。已有的data-qb-typography等记录由系统管理，不手写或改造其内容。不改变选中区域以外字段的定义、值或主题配色。
- 字号、行距、对齐、边框和留白使用安全内联样式；长文不用固定高度、零高度或零行高。用户只要求一种属性变化时保留其他设计。
- 图表使用原data-qb-chart和字段，类型、配色可按要求调整；锁定数据时不能改数值或分类。不手绘空圆、渐变或SVG。
- 返回标准组件JSON中的name、description、category、tags、html、fields、values。fields与values仅包含本区域相关字段，不生成无关示例。

系统会检查根元素、锁定内容、字段与图片引用，并在确认时再次核对原文章版本及元素指纹。结构大改的选中区域会作为局部独立样式保存；其他区域保持原样。若收到检查错误，只修复错误后返回完整JSON。
